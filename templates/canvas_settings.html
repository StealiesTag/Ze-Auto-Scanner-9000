Canvas LMS

Canvas is optional. Paparazzi sends grades only after you preview them and confirm the upload. This local, single-teacher app uses a development personal access token; a multi-teacher deployment should use institution-approved OAuth.

Keep Paparazzi bound to localhost. Canvas connections and grade actions are restricted to local browser requests. Use an HTTPS Canvas institution URL. The token is encrypted on the server and never sent to the browser after saving.
