One-time ESP32 setup

Save the local camera address once. The live MJPEG feed is only a preview; scanning reads still images from the ESP32 capture URL so it does not compete with the preview stream.

Load completed answer sheets for feeding. The automatic scan prints one blank A4 page per cycle using the system default printer; set A4 paper and disable duplex in printer preferences before scanning.

Capture controls

One-time setup required on the computer connected to the printer. Silent printing sends each blank page straight to the default printer. Configure the browser first; Paparazzi cannot change browser or Windows settings for you.
Show teacher setup steps

1. Set up the printer in Windows

  1. Open Settings → Bluetooth & devices → Printers & scanners.
  2. Select the printer that will feed the answer sheets and choose Set as default. If Windows manages the default printer automatically, turn that option off first.
  3. Open that printer's printing preferences. Set paper to A4 and turn two-sided / duplex printing off.

2. Choose one browser setup

Chrome (recommended):

  1. Close every Chrome window.
  2. Find Chrome in the Windows Start menu, right-click it, then choose Open file location.
  3. In the folder that opens, right-click the Chrome shortcut and choose Properties.
  4. On the Shortcut tab, click the end of the Target field. Add a space and --kiosk-printing after the closing quote. Keep the existing path. It should look similar to:
    "C:\Program Files\Google\Chrome\Application\chrome.exe" --kiosk-printing
  5. Choose Apply, then OK. From now on, open Paparazzi using this edited shortcut.

Microsoft Edge: Edge silent printing is controlled by a Windows policy and needs Edge policy templates and administrator access. Ask your IT administrator to enable Enable Silent Printing at Computer Configuration → Administrative Templates → Microsoft Edge, then restart Edge. This policy is supported in Edge 144 and later. Microsoft's setup and version details.

3. Check before scanning

  1. Open Paparazzi in the configured browser and select the assessment.
  2. Check Silent printing is configured on this computer, then choose Start one-page scanning.
  3. The printer should feed one blank page without showing a print dialog. If a print dialog appears, choose Stop in Paparazzi, close the browser, and check the setup above before trying again.

This setup is per computer. The checkbox remembers your confirmation in this browser; the page cannot verify the browser policy itself.

Load completed answer sheets in the printer tray. Paparazzi initiates one blank-page print, waits six seconds, takes a still, and repeats. The second consecutive capture of the same sheet is treated as the empty-feed signal and is not graded again.

The Flask server coordinates printer steps and captures. The separate worker only grades queued images; start or restart it with python -m services.scan_worker. If the queue fills or a capture fails, scanning pauses before requesting another page.
