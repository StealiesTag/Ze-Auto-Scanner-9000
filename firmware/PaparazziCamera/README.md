# Paparazzi ESP32 camera firmware

This firmware removes Wi-Fi credentials from the sketch. A camera builder flashes it once for the exact camera board; teachers enter their Wi-Fi details through a password-protected local setup page. Credentials are stored in the ESP32's Preferences/NVS storage. They are not sent to Paparazzi, Muse, or Canvas.

## One-time camera-builder setup

1. Install the Espressif ESP32 Arduino board package and open its **CameraWebServer** example.
2. In `board_config.h`, select the exact camera board model. Keep the matching `board_config.h`, `app_httpd.cpp`, and `camera_index.h` files with the sketch.
3. Replace the example `.ino` with `PaparazziCamera.ino` from this folder and upload it once. It keeps the requested SVGA, JPEG quality 20, brightness 2, contrast 2, and saturation 0 startup settings.
4. Open Serial Monitor at 115200 baud. On first boot, copy the printed **Setup network** and **Setup network password** onto a label attached to that camera. The random WPA2 setup password is stored on the ESP32, so it remains the same across reboots. Do not put the Wi-Fi password on this label or share the Serial Monitor log.

`board_config.h` is intentionally board-specific. The teacher does not change that file or edit Wi-Fi values. The camera advertises `_paparazzi-camera._tcp.local.` after joining Wi-Fi so the Paparazzi app's **Find camera on Wi-Fi** button can save its address automatically.

## Teacher first-time setup

1. Power on the camera and connect a phone to the **Paparazzi-Setup-xxxxxx** network printed on its label. Enter that network's setup password from the same label. If the phone says the network has no internet, stay connected.
2. Open `http://192.168.4.1`, choose the classroom Wi-Fi, enter its password, and press **Save Wi-Fi and connect camera**.
3. Connect the Paparazzi computer to that same Wi-Fi network. In **Automatic scanning**, press **Find camera on Wi-Fi**.

The camera saves Wi-Fi details locally and reconnects on later power-ups. Camera discovery uses local multicast DNS; some school Wi-Fi networks block device-to-device multicast. If discovery cannot find the camera, ask school IT to allow local device discovery or use the advanced manual address fields in Paparazzi.

The camera setup page is served only on a WPA2-protected setup network. Its unique setup password is generated by the firmware and printed once for the camera label. The teacher's Wi-Fi password is sent only to the camera over that protected local connection.

This firmware has not been compiled or flashed against a physical board in this workspace. Confirm the board selection and camera pin map on the camera-builder's computer before deployment.
